  🚀 БЫСТРЫЙ ДЕПЛОЙ НА VERCEL - ВЫПОЛНИТЕ ЭТИ КОМАНДЫ

Откройте PowerShell и выполните команды по порядку:

1. Перейдите в папку miniapp:
   cd miniapp

2. Авторизуйтесь в Vercel (если еще не авторизованы):
   vercel login

3. Свяжите проект с Vercel:
   vercel link
   → Выберите "Link to existing project" или "Create new project"

4. Добавьте переменные окружения (если еще не добавлены):
   vercel env add NEXT_PUBLIC_SUPABASE_URL
   vercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY
   vercel env add SUPABASE_SERVICE_ROLE_KEY
   
   Для каждой переменной введите значение и выберите окружения.

5. Выполните деплой:
   vercel --prod

ИЛИ используйте веб-интерфейс (проще для первого раза):

1. Откройте: https://vercel.com/new
2. Выберите репозиторий step-one-app
3. Root Directory: miniapp
4. Добавьте переменные окружения
5. Deploy
