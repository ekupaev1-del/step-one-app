СПОСОБ 1: Через Vercel Dashboard (САМЫЙ ПРОСТОЙ - 30 секунд)
───────────────────────────────────────────────────────────────
1. Откройте: https://vercel.com/dashboard
2. Найдите ваш проект
3. Нажмите кнопку "Redeploy" или "Deploy"
4. Готово! ✅

───────────────────────────────────────────────────────────────

СПОСОБ 2: Через командную строку (если авторизованы)
───────────────────────────────────────────────────────────────
Откройте PowerShell и выполните:

cd miniapp
vercel --prod

───────────────────────────────────────────────────────────────

СПОСОБ 3: Если не авторизованы
───────────────────────────────────────────────────────────────
1. cd miniapp
2. vercel login
3. vercel link (если проект не связан)
4. vercel --prod

───────────────────────────────────────────────────────────────

СПОСОБ 4: Через GitHub (если настроен автоматический деплой)
───────────────────────────────────────────────────────────────
1. Сделайте любой коммит:
   git add .
   git commit -m "Trigger deployment"
   git push

2. GitHub Actions автоматически задеплоит

═══════════════════════════════════════════════════════════════

РЕКОМЕНДАЦИЯ: Используйте Способ 1 (через Dashboard) - 
              это самый быстрый и надежный способ!
