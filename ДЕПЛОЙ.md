# 🚀 Деплой на Vercel

## Автоматический деплой через Git интеграцию

Этот проект использует **нативную Git интеграцию Vercel** для автоматических деплоев.

### Как это работает

1. **Push в GitHub** → Запушьте код в ветку `main`
2. **Vercel автоматически деплоит** → Vercel получает webhook от GitHub
3. **Готово!** → Ваше приложение задеплоено

**Никаких дополнительных действий не требуется!**

## 📋 Первоначальная настройка (один раз)

### Шаг 1: Подключите репозиторий к Vercel

1. Откройте [Vercel Dashboard](https://vercel.com/dashboard)
2. Нажмите **"Add New Project"**
3. Выберите ваш GitHub репозиторий `step-one-app`
4. Настройки проекта:
   - **Root Directory**: `miniapp` ⚠️ **ВАЖНО!**
   - Framework определится автоматически (Next.js)
5. Нажмите **"Deploy"**

### Шаг 2: Добавьте переменные окружения

В Vercel Dashboard → Ваш проект → Settings → Environment Variables добавьте:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

⚠️ **Важно**: Установите для всех окружений (Production, Preview, Development)

### Шаг 3: Проверьте деплой

1. Проверьте Vercel Dashboard → Deployments
2. Откройте production URL
3. Проверьте health check: `https://your-project.vercel.app/api/version`

## ✅ После настройки

После подключения **каждый push в `main` автоматически запускает новый production деплой**.

- ✅ Никаких ручных действий
- ✅ Никаких CLI команд
- ✅ Никаких токенов
- ✅ Автоматические сборки и деплои

## 🔍 Проверка деплоев

### В Vercel Dashboard

1. Откройте [Vercel Dashboard](https://vercel.com/dashboard)
2. Выберите ваш проект
3. Вкладка **"Deployments"**
4. Вы увидите:
   - Все деплои (production и preview)
   - Статус деплоя (Building, Ready, Error)
   - Commit SHA и сообщение
   - URL деплоя
   - Логи сборки

### Через Health Check

Откройте: `https://your-project.vercel.app/api/version`

Вернет информацию о версии, commit SHA и времени деплоя.

## 🔧 Решение проблем

### Деплой не запускается

**Проблема**: Push в `main` не запускает деплой

**Решение**: Проверьте Git интеграцию
1. Vercel Dashboard → Project → Settings → Git
2. Убедитесь, что репозиторий подключен
3. Проверьте, что "Production Branch" установлен на `main`
4. Если отключен, нажмите **"Disconnect"**, затем **"Connect Git Repository"** снова

### Проблемы с webhook

**Проблема**: Git интеграция перестала работать

**Решение**: Переподключите Git интеграцию
1. Vercel Dashboard → Project → Settings → Git
2. Нажмите **"Disconnect"**
3. Нажмите **"Connect Git Repository"**
4. Выберите репозиторий снова
5. Vercel автоматически пересоздаст webhooks

## 📝 Ручной деплой (если нужно)

Если нужно запустить деплой вручную:

1. Vercel Dashboard → Project → Deployments
2. Нажмите **"Redeploy"** на последнем деплое
3. Или **"Deploy"** → Выберите ветку → Deploy
