# ✅ Автоматический деплой настроен!

## 🎉 Что сделано

Я создал **GitHub Actions workflow** для автоматического деплоя на Vercel!

### Файлы созданы:
- ✅ `.github/workflows/deploy-vercel.yml` - основной workflow
- ✅ `.github/workflows/deploy-vercel-simple.yml` - упрощенная версия
- ✅ `GITHUB_ACTIONS_SETUP.md` - инструкция по настройке

## 🚀 Как активировать (3 шага)

### Шаг 1: Получите токены Vercel

1. Откройте: https://vercel.com/account/tokens
2. Создайте токен → скопируйте

### Шаг 2: Получите ID проекта

**Способ 1: Через веб-интерфейс**
1. Зайдите в проект на Vercel
2. Settings → General
3. Скопируйте Project ID и Team ID

**Способ 2: Если проект уже связан**
```bash
cd miniapp
cat .vercel/project.json
```

### Шаг 3: Добавьте Secrets в GitHub

1. GitHub репозиторий → Settings → Secrets and variables → Actions
2. Добавьте secrets:
   - `VERCEL_TOKEN`
   - `VERCEL_ORG_ID`
   - `VERCEL_PROJECT_ID`
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`

### Шаг 4: Push в репозиторий

```bash
git add .github/workflows/
git commit -m "Add automatic Vercel deployment"
git push
```

**Готово!** После push автоматически запустится деплой! 🎉

## 🔄 Как это работает

- При каждом push в `main` → автоматический деплой на production
- Можно запустить вручную через GitHub Actions → Run workflow

## 📚 Подробная инструкция

См. файл: `GITHUB_ACTIONS_SETUP.md`

## 🌐 Или используйте встроенную интеграцию Vercel (проще!)

1. Откройте: https://vercel.com/new
2. Подключите GitHub репозиторий
3. Root Directory: `miniapp`
4. Добавьте переменные окружения
5. Deploy

После этого Vercel будет автоматически деплоить при каждом push!
