# ⚡ ВЫПОЛНИТЬ МИГРАЦИИ СЕЙЧАС

## Готовый SQL код для копирования

Файл `migrations/run-all-migrations.sql` содержит весь необходимый SQL код.

## Инструкция (3 шага):

1. **Откройте файл:** `migrations/run-all-migrations.sql`
2. **Скопируйте весь код** (Ctrl+A, Ctrl+C)
3. **Вставьте в Supabase SQL Editor:**
   - Откройте https://app.supabase.com
   - Выберите ваш проект
   - Перейдите в SQL Editor
   - Вставьте код (Ctrl+V)
   - Нажмите "Run" или Ctrl+Enter

## Что будет создано:

✅ **Таблица `payments`** - для хранения платежей
✅ **Таблица `subscriptions`** - для хранения подписок
✅ **Индексы** - для быстрого поиска
✅ **Триггеры** - для автоматического обновления дат

## После выполнения:

Подождите 1-2 минуты для обновления кеша схемы, затем система подписки будет готова к работе!
