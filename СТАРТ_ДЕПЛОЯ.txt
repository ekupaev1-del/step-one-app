📋 ЧТО НУЖНО СДЕЛАТЬ (5 минут):

1. Откройте: https://vercel.com/new

2. Нажмите "Import Git Repository"
   → Выберите ваш репозиторий step-one-app
   → Нажмите "Import"

3. В настройках проекта укажите:
   ⚠️  Root Directory: miniapp  (ОБЯЗАТЕЛЬНО!)

4. Добавьте переменные окружения:
   SUPABASE_URL=...
   SUPABASE_SERVICE_ROLE_KEY=...
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   
   Выберите: ✅ Production, ✅ Preview, ✅ Development

5. Нажмите "Deploy"

✅ ПОСЛЕ НАСТРОЙКИ:

Просто делайте push в GitHub:
   git push origin main  → автоматический production деплой
   git push origin dev   → автоматический preview деплой

Vercel автоматически задеплоит изменения!
