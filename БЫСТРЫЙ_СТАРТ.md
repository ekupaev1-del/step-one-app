# ⚡ Быстрый старт: Автоматический деплой в Vercel

## 🎯 Самый простой способ (3 минуты)

### 1. Откройте Vercel Dashboard
👉 https://vercel.com/new

### 2. Подключите GitHub репозиторий
- Нажмите **"Import Git Repository"**
- Выберите `step-one-app`
- Нажмите **"Import"**

### 3. Настройте проект
**ВАЖНО:** Укажите:
- **Root Directory**: `miniapp` ⚠️
- **Production Branch**: `main`

### 4. Добавьте переменные окружения
В разделе **Environment Variables** добавьте:
```
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<key>
NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<key>
```

Выберите: ✅ Production, ✅ Preview, ✅ Development

### 5. Нажмите "Deploy"

---

## ✅ Готово!

Теперь просто делайте push:

```bash
git push origin main    # → автоматический production деплой
git push origin dev     # → автоматический preview деплой
```

**Всё! Vercel автоматически задеплоит при каждом push.**
