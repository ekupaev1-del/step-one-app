# ⚡ ЧТО ДЕЛАТЬ СЕЙЧАС - Автоматический деплой

## 🎯 ПРОСТАЯ ИНСТРУКЦИЯ (3 шага)

### 1️⃣ Откройте Vercel и подключите GitHub

👉 **Откройте:** https://vercel.com/new

1. Нажмите **"Import Git Repository"**
2. Если репозиторий не виден:
   - Нажмите **"Adjust GitHub App Permissions"**
   - Дайте доступ к репозиторию `ekupaev1-del/step-one-app`
3. Выберите репозиторий: **ekupaev1-del/step-one-app**
4. Нажмите **"Import"**

---

### 2️⃣ Настройте проект

**⚠️ ВАЖНО - укажите эти настройки:**

- **Root Directory**: `miniapp` ⚠️ **ОБЯЗАТЕЛЬНО!**
- **Production Branch**: `main`
- Остальное оставьте по умолчанию

**НЕ НАЖИМАЙТЕ "Deploy" пока!**

---

### 3️⃣ Добавьте переменные окружения

1. Нажмите **"Environment Variables"** (слева внизу формы)
2. Добавьте переменные (нажмите "Add" для каждой):

```
SUPABASE_URL
= https://<ваш-project-ref>.supabase.co

SUPABASE_SERVICE_ROLE_KEY
= <ваш-service-role-key>

EXPECTED_SUPABASE_PROJECT_REF
= <ваш-project-ref>

NEXT_PUBLIC_SUPABASE_URL
= https://<ваш-project-ref>.supabase.co

NEXT_PUBLIC_SUPABASE_ANON_KEY
= <ваш-anon-key>
```

3. Для каждой переменной выберите окружения:
   - ✅ **Production**
   - ✅ **Preview**
   - ✅ **Development**

---

### 4️⃣ Нажмите "Deploy"

Готово! 🎉

---

## ✅ После настройки

**Автоматический деплой работает!**

Теперь каждый push в GitHub автоматически запускает деплой:

```bash
git push origin main    # → автоматический production деплой
git push origin dev     # → автоматический preview деплой
```

**Vercel автоматически:**
- ✅ Определит изменения
- ✅ Запустит сборку
- ✅ Задеплоит новую версию

---

## 🔍 Проверка работы

После настройки сделайте тестовый push:

```bash
git commit --allow-empty -m "Test auto deploy"
git push origin main
```

**Проверьте через 1-2 минуты:**
- Vercel Dashboard → Deployments
- Должен появиться новый деплой автоматически!

---

## 🆘 Если не работает

1. **Проверьте настройки Git в Vercel:**
   - Dashboard → Settings → Git
   - Репозиторий должен быть подключен
   - Root Directory = `miniapp`

2. **Проверьте, что есть push в Git:**
   - Vercel реагирует только на push в GitHub

3. **Проверьте логи:**
   - Dashboard → Deployments → выберите деплой → Build Logs
