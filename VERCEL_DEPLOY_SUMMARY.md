# ✅ Автоматический деплой через Git Push

## 🎯 Как это работает

**Просто push в GitHub → Vercel автоматически деплоит!**

```bash
git push origin main  # → автоматический production деплой
git push origin dev   # → автоматический preview деплой
```

**Никаких CLI, никаких дополнительных команд. Просто push!**

---

## ⚡ Настройка (один раз, 3 минуты)

### 1. Vercel Dashboard → Add New Project
### 2. Root Directory: `miniapp`
### 3. Добавьте переменные окружения
### 4. Deploy → готово!

**Подробно:** `VERCEL_AUTO_DEPLOY.md`

---

## ✅ Всё!

После настройки просто делайте `git push` → автоматический деплой работает.
