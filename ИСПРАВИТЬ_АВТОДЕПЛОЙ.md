# 🔧 Исправление автоматического деплоя в Vercel

## Проблема
Git подключен, но автоматический деплой не запускается при push в `main`.

## Решение

### Шаг 1: Проверьте настройки проекта в Vercel

Зайдите в **Vercel Dashboard** → ваш проект → **Settings**

#### 1.1. General → Root Directory
**КРИТИЧНО!** Должно быть:
```
miniapp
```
Если пусто или другое значение → исправьте!

#### 1.2. Git → Production Branch
Должно быть:
```
main
```

#### 1.3. Git → Ignored Build Step
Должно быть **ПУСТО** или правильная команда.

Если там что-то вроде:
```
git diff HEAD^ HEAD --quiet .
```
→ **УДАЛИТЕ** это! Это блокирует деплой.

#### 1.4. Git → Deployment Protection
Убедитесь, что не включена защита, которая блокирует автоматический деплой.

---

### Шаг 2: Переподключите Git (если нужно)

1. **Settings** → **Git** → **Disconnect**
2. **Connect Repository** → выберите `ekupaev1-del/step-one-app`
3. Укажите:
   - **Root Directory**: `miniapp` ⚠️
   - **Production Branch**: `main`

---

### Шаг 3: Проверьте webhook в GitHub

1. GitHub → ваш репозиторий → **Settings** → **Webhooks**
2. Должен быть webhook от Vercel
3. Проверьте последние доставки (Recent Deliveries)
4. Если есть ошибки → переподключите Git в Vercel

---

### Шаг 4: Тестовый push

После исправления настроек:
```bash
git commit --allow-empty -m "Test auto deploy after settings fix"
git push origin main
```

**Проверьте через 30 секунд:**
- Vercel Dashboard → Deployments
- Должен появиться новый деплой автоматически!

---

## 🆘 Если всё равно не работает

### Вариант 1: Запустить деплой вручную
```bash
cd miniapp
vercel --prod
```

### Вариант 2: Использовать GitHub Actions
Уже настроен workflow в `.github/workflows/deploy.yml`
- Он автоматически деплоит при push в `main` или `dev`
- Нужно только добавить secrets в GitHub (см. DEPLOY_SETUP.md)

---

## ✅ Ожидаемый результат

После исправления:
- Каждый push в `main` → автоматический production деплой
- Каждый push в `dev` → автоматический preview деплой
- Деплои появляются в Vercel Dashboard через 30-60 секунд после push
