# 🚀 Автоматический деплой в Vercel - Пошаговая инструкция

## ⚡ Быстрая настройка (5 минут)

### Шаг 1: Откройте Vercel Dashboard

👉 **Перейдите по ссылке:** https://vercel.com/new

### Шаг 2: Подключите GitHub репозиторий

1. Нажмите **"Import Git Repository"**
2. Выберите ваш репозиторий `step-one-app`
3. Если репозиторий не виден, нажмите **"Adjust GitHub App Permissions"** и дайте доступ
4. Нажмите **"Import"**

### Шаг 3: Настройте проект

**⚠️ ВАЖНО:** Укажите эти настройки:

- **Project Name**: `step-one-app` (или любое другое имя)
- **Root Directory**: `miniapp` ⚠️ **ОБЯЗАТЕЛЬНО!**
- **Framework Preset**: Next.js (определится автоматически)
- **Build Command**: `npm run build` (уже настроено в vercel.json)
- **Output Directory**: `.next` (уже настроено в vercel.json)
- **Install Command**: `npm install` (уже настроено в vercel.json)

**Production Branch**: `main` (по умолчанию)

### Шаг 4: Добавьте переменные окружения

**ПЕРЕД нажатием кнопки "Deploy":**

1. Нажмите **"Environment Variables"**
2. Добавьте следующие переменные:

```
SUPABASE_URL=https://<ваш-project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<ваш-service-role-key>
EXPECTED_SUPABASE_PROJECT_REF=<ваш-project-ref>
NEXT_PUBLIC_SUPABASE_URL=https://<ваш-project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<ваш-anon-key>
```

3. Для каждой переменной выберите окружения:
   - ✅ **Production**
   - ✅ **Preview**
   - ✅ **Development**

### Шаг 5: Нажмите "Deploy"

Готово! 🎉 Vercel начнет деплой.

## ✅ После настройки - Автоматический деплой работает!

Теперь **каждый push в GitHub автоматически запускает деплой:**

```bash
git push origin main    # → автоматический production деплой
git push origin dev     # → автоматический preview деплой
```

**Vercel автоматически:**
- ✅ Определит изменения в Git
- ✅ Запустит сборку проекта
- ✅ Задеплоит новую версию
- ✅ Обновит URL

**Никаких дополнительных действий не нужно!**

1. **Vercel Dashboard** → **Deployments**
   - Список всех деплоев
   - Статус каждого деплоя (Ready, Building, Error)

   - Статус workflow
   - Логи выполнения

## 🔧 Дополнительные настройки (опционально)

### Настройка Preview деплоев для всех веток

1. Vercel Dashboard → **Settings** → **Git**
2. Убедитесь, что **"Production Branch"** = `main`
3. Preview деплои создаются автоматически для всех остальных веток

### Настройка домена

1. Vercel Dashboard → **Settings** → **Domains**
2. Добавьте свой домен (если есть)
3. Настройте DNS записи по инструкции Vercel

## 🐛 Решение проблем

### Деплой не запускается автоматически

**Проверьте:**
- ✅ Репозиторий подключен в Vercel Dashboard
- ✅ Root Directory = `miniapp` в настройках проекта
- ✅ Production Branch = `main`
- ✅ Есть push в Git (Vercel реагирует на push)

**Решение:**
1. Vercel Dashboard → **Settings** → **Git**
2. Проверьте настройки
3. Попробуйте сделать тестовый push:
   ```bash
   git commit --allow-empty -m "Test deploy"
   git push origin main
   ```

### Ошибка сборки

**Проверьте логи:**
1. Vercel Dashboard → **Deployments** → выберите деплой
2. Откройте **"Build Logs"**
3. Найдите ошибку

**Частые проблемы:**
- ❌ Отсутствуют переменные окружения → добавьте в Settings → Environment Variables
- ❌ Неправильный Root Directory → укажите `miniapp`
- ❌ Ошибки в коде → исправьте ошибки и сделайте новый push

### Переменные окружения не работают

**Проверьте:**
- ✅ Переменные добавлены для нужных окружений (Production/Preview/Development)
- ✅ Имена переменных правильные (без лишних пробелов)
- ✅ Значения переменных правильные

**Решение:**
1. Vercel Dashboard → **Settings** → **Environment Variables**
2. Проверьте каждую переменную
3. Перезапустите деплой после изменения переменных

## 🎯 Проверка работы

### Тест 1: Production деплой

```bash
git checkout main
git commit --allow-empty -m "Test production deploy"
git push origin main
```

**Проверьте:**
- Vercel Dashboard → Deployments → должен появиться новый деплой
- Статус должен быть "Ready" через 1-2 минуты
- URL должен быть доступен

### Тест 2: Preview деплой

```bash
git checkout dev
git commit --allow-empty -m "Test preview deploy"
git push origin dev
```

**Проверьте:**
- Vercel Dashboard → Deployments → должен появиться новый preview деплой
- Должен быть уникальный preview URL
