# 🚀 Автоматический деплой на Vercel

## ⚡ Самый быстрый способ (если проект уже настроен)

Если вы уже связали проект с Vercel и добавили переменные окружения:

```powershell
cd miniapp
vercel --prod --yes
```

---

## 🔧 Первоначальная настройка (один раз)

Если проект еще не настроен, выполните эти шаги один раз:

### 1. Авторизация
```powershell
cd miniapp
vercel login
```
Откроется браузер для авторизации.

### 2. Связывание проекта
```powershell
vercel link
```
Выберите:
- **Link to existing project** → выберите проект из списка
- Или **Create new project** → введите имя проекта

### 3. Добавление переменных окружения
```powershell
vercel env add NEXT_PUBLIC_SUPABASE_URL
vercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY
vercel env add SUPABASE_SERVICE_ROLE_KEY
```

Для каждой переменной:
- Введите значение
- Выберите окружения: нажмите Enter для всех (Production, Preview, Development)

### 4. Деплой!
```powershell
vercel --prod
```

---

## 📝 Готовый скрипт для автоматизации

Создан файл `setup-and-deploy.ps1` в корне проекта.

Запустите из корня:
```powershell
.\setup-and-deploy.ps1
```

Скрипт автоматически:
- ✅ Проверит Vercel CLI
- ✅ Авторизует (если нужно)
- ✅ Свяжет проект (если нужно)
- ✅ Проверит переменные окружения
- ✅ Выполнит деплой

---

## 🌐 Или через веб-интерфейс (рекомендуется для первого раза)

1. Откройте: https://vercel.com/new
2. Выберите репозиторий `step-one-app`
3. **Root Directory**: `miniapp` ⚠️
4. Добавьте переменные окружения
5. Deploy → Готово!

После этого все последующие деплои будут автоматическими при push в репозиторий.

---

## ✅ Проверка после деплоя

1. Откройте Vercel Dashboard: https://vercel.com/dashboard
2. Найдите ваш проект
3. Откройте URL (например, `https://your-project.vercel.app`)
4. Проверьте API: `/api/health`

---

## 🔄 Автоматический деплой при push

После первоначальной настройки через веб-интерфейс:
- Push в `main` → автоматический production деплой
- Push в другие ветки → автоматический preview деплой

Никаких дополнительных действий не требуется! 🎉
