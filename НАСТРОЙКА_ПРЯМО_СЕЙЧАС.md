# 🚀 Настройка автоматического деплоя ПРЯМО СЕЙЧАС

## ⚡ Способ 1: Через Vercel Dashboard (САМЫЙ ПРОСТОЙ - 3 минуты)

### Шаг 1: Откройте Vercel
👉 **https://vercel.com/new**

### Шаг 2: Подключите GitHub
1. Нажмите **"Import Git Repository"**
2. Если репозиторий не виден, нажмите **"Adjust GitHub App Permissions"**
3. Выберите репозиторий: **ekupaev1-del/step-one-app**
4. Нажмите **"Import"**

### Шаг 3: Настройте проект
**⚠️ ВАЖНО - укажите эти настройки:**

- **Project Name**: `step-one-app` (или любое другое)
- **Root Directory**: `miniapp` ⚠️ **ОБЯЗАТЕЛЬНО!**
- **Framework Preset**: Next.js (определится автоматически)
- **Production Branch**: `main`

**НЕ НАЖИМАЙТЕ "Deploy" пока!**

### Шаг 4: Добавьте переменные окружения
1. Нажмите **"Environment Variables"** (слева внизу)
2. Добавьте переменные:

```
SUPABASE_URL=https://<ваш-project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<ваш-service-role-key>
EXPECTED_SUPABASE_PROJECT_REF=<ваш-project-ref>
NEXT_PUBLIC_SUPABASE_URL=https://<ваш-project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<ваш-anon-key>
```

3. Для каждой переменной выберите окружения:
   - ✅ **Production**
   - ✅ **Preview**  
   - ✅ **Development**

### Шаг 5: Нажмите "Deploy"
Готово! 🎉

## ✅ После настройки - проверка

После того как проект подключен к Vercel через Git:

1. **Сделайте тестовый push:**
   ```bash
   git commit --allow-empty -m "Test auto deploy"
   git push origin main
   ```

2. **Проверьте Vercel Dashboard:**
   - https://vercel.com/dashboard
   - Откройте ваш проект
   - Перейдите в **Deployments**
   - Должен появиться новый деплой автоматически!

---

## 🔧 Если деплой не запускается автоматически

### Проверьте настройки Git в Vercel:

1. Vercel Dashboard → ваш проект → **Settings** → **Git**
2. Убедитесь, что:
   - ✅ Репозиторий подключен
   - ✅ **Production Branch** = `main`
   - ✅ **Root Directory** = `miniapp`

### Проверьте, что есть push в Git:

```bash
git log --oneline -5
git status
```

Если нет изменений, сделайте тестовый коммит:

```bash
git commit --allow-empty -m "Test deploy"
git push origin main
```

## 📊 Где смотреть деплои

- **Vercel Dashboard** → **Deployments**
  - Список всех деплоев
  - Статус каждого деплоя
  - Логи сборки

- **GitHub** → **Actions** (если настроен GitHub Actions)
  - Статус workflow
  - Логи выполнения

## 🆘 Если ничего не работает

1. **Проверьте, что проект подключен к Vercel:**
   - Vercel Dashboard → должен быть ваш проект

2. **Проверьте настройки Git:**
   - Settings → Git → репозиторий должен быть подключен

3. **Проверьте Root Directory:**
   - Должно быть `miniapp`

4. **Сделайте push в GitHub:**
   - Vercel реагирует только на push в Git

5. **Проверьте логи:**
   - Vercel Dashboard → Deployments → выберите деплой → Build Logs

---

## ✅ Готово!
