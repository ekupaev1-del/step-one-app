# 🚀 Деплой прямо сейчас

## Способ 1: Через командную строку (если авторизованы)

```powershell
cd miniapp
vercel --prod
```

Или используйте скрипт:
```powershell
cd miniapp
.\deploy-now.ps1
```

## Способ 2: Если не авторизованы

### Шаг 1: Авторизация
```powershell
cd miniapp
vercel login
```
Откроется браузер для авторизации.

### Шаг 2: Связывание проекта (если нужно)
```powershell
vercel link
```

### Шаг 3: Деплой
```powershell
vercel --prod
```

## Способ 3: Через веб-интерфейс (самый простой)

1. **Откройте**: https://vercel.com/dashboard
2. Найдите ваш проект
3. Нажмите **"Redeploy"** или **"Deploy"**
4. Или перейдите в **Deployments** → выберите последний деплой → **Redeploy**

## Способ 4: Через GitHub (если настроен)

1. Сделайте любой коммит:
```bash
git add .
git commit -m "Trigger deployment"
git push
```

2. GitHub Actions автоматически задеплоит (если настроен)

---

## ⚡ Самый быстрый способ

Если проект уже настроен в Vercel Dashboard:

1. Откройте: https://vercel.com/dashboard
2. Найдите проект
3. Нажмите **"Redeploy"** → Готово! ✅

---

## 🔍 Проверка деплоя

После деплоя:
1. Откройте URL проекта в Vercel Dashboard
2. Проверьте: `https://your-project.vercel.app/api/health`
3. Проверьте логи в Vercel Dashboard → Deployments
