## ✅ Тестовый коммит создан и запушен

**Время:** Сейчас  
**Ветка:** `main`  
**Коммит:** `Test: Vercel auto-deploy check`

---

## ⏱️ Что происходит сейчас

Vercel должен автоматически:

1. **Получить webhook** от GitHub (в течение 5-10 секунд)
2. **Запустить деплой** (через 10-30 секунд после webhook)
3. **Собрать проект** (1-2 минуты)
4. **Задеплоить** в production

**Общее время:** 1-3 минуты от момента push

---

## 📊 Где проверить деплой

### Vercel Dashboard

**Откройте:** https://vercel.com/dashboard

1. Выберите ваш проект
2. Перейдите на вкладку **"Deployments"**
3. Найдите самый верхний деплой (самый новый)
4. Проверьте:
   - ✅ **Источник:** GitHub
   - ✅ **Ветка:** `main`
   - ✅ **Коммит:** Ваш тестовый коммит
   - ✅ **Статус:** Building → Ready (или Error, но деплой ДОЛЖЕН появиться)

---

## 🔍 Если деплой не появился

### Быстрая проверка настроек

#### 1. Vercel → Settings → General
- **Root Directory:** `miniapp` ⚠️ **КРИТИЧНО**

#### 2. Vercel → Settings → Git
- **Production Branch:** `main`
- **Connected Repository:** `ekupaev1-del/step-one-app`
- **Ignored Build Step:** ⚠️ **ДОЛЖНО БЫТЬ ПУСТЫМ**

#### 3. GitHub → Settings → Webhooks
- Должен быть активный webhook с URL `vercel.com`
- Recent Deliveries: последний push должен иметь статус `200`

---

## 🛠️ Если нужно переподключить

Если деплой не появляется, переподключите Git:

1. **Vercel Dashboard → Settings → Git**
2. Нажмите **"Disconnect"**
3. Нажмите **"Connect Repository"**
4. Выберите `ekupaev1-del/step-one-app`
5. Установите:
   - **Root Directory:** `miniapp`
   - **Production Branch:** `main`
6. Нажмите **"Connect"**

После переподключения:
- Webhook будет пересоздан автоматически
- GitHub App будет переустановлен
- Следующий push должен создать деплой
