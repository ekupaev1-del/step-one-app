# Промпт для изменения логики цветов календаря

## Задача

Изменить логику цветовой индикации дней в календаре отчетов на основе соотношения потребленных калорий к дневной норме.

## Требования к цветам

### 🟢 Зеленый цвет
- **Условие**: Человек питается ровно (в пределах ±15% от нормы)
- **Диапазон**: От 85% до 115% от целевых калорий
- **Пример**: Если норма 2000 ккал, то зеленый будет от 1700 до 2300 ккал

### 🔴 Красный цвет
- **Условие**: Переедание более чем на 15% от нормы
- **Диапазон**: Больше 115% от целевых калорий
- **Пример**: Если норма 2000 ккал, то красный будет при потреблении больше 2300 ккал

### 🟡 Желтый цвет
- **Условие**: Недоедание более чем на 15% от нормы
- **Диапазон**: Меньше 85% от целевых калорий
- **Пример**: Если норма 2000 ккал, то желтый будет при потреблении меньше 1700 ккал

### ⚪ Серый (без цвета)
- **Условие**: Нет данных за день или не задана целевая норма калорий

## Файл для изменения

`miniapp/app/api/report/calendar/route.ts`

## Функция для изменения

```typescript
function getDayStatus(actualCalories: number, targetCalories: number): "green" | "yellow" | "red" | "none"
```

## Логика реализации

1. Проверить наличие целевых калорий (`targetCalories`)
2. Проверить наличие фактических калорий (`actualCalories`)
3. Вычислить процент: `(actualCalories / targetCalories) * 100`
4. Применить правила:
   - Если процент >= 85 И процент <= 115 → `"green"`
   - Если процент > 115 → `"red"`
   - Если процент < 85 → `"yellow"`
   - Если нет данных → `"none"`

## Пример кода

```typescript
function getDayStatus(actualCalories: number, targetCalories: number): "green" | "yellow" | "red" | "none" {
  if (!targetCalories || targetCalories <= 0) {
    return "none";
  }

  if (actualCalories <= 0) {
    return "none";
  }

  // Вычисляем процент от нормы
  const percentage = (actualCalories / targetCalories) * 100;

  // Зеленый: в пределах ±15% от нормы (85% - 115%)
  if (percentage >= 85 && percentage <= 115) {
    return "green";
  }

  // Красный: переедание более 15% (>115%)
  if (percentage > 115) {
    return "red";
  }

  // Желтый: недоедание более 15% (<85%)
  return "yellow";
}
```

## Изменение порогов

Если нужно изменить порог с 15% на другое значение (например, 10% или 20%):

- Для ±10%: изменить `85` на `90` и `115` на `110`
- Для ±20%: изменить `85` на `80` и `115` на `120`

Формула:
- Нижняя граница = `100 - процент_порога`
- Верхняя граница = `100 + процент_порога`
