# 🚀 Быстрый деплой на Vercel - Прямо сейчас!

## Вариант 1: Через Vercel Dashboard (Самый простой - 2 минуты)

1. **Откройте**: https://vercel.com/new
2. **Выберите** ваш репозиторий `step-one-app`
3. **Настройки проекта**:
   - Root Directory: `miniapp` ⚠️ **ВАЖНО!**
   - Framework: Next.js (автоматически)
4. **Environment Variables** (добавьте):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
5. **Deploy** → Готово! ✅

---

## Вариант 2: Через командную строку

### Шаг 1: Перейдите в папку miniapp
```powershell
cd miniapp
```

### Шаг 2: Авторизуйтесь (если еще не авторизованы)
```powershell
vercel login
```

### Шаг 3: Свяжите проект (если еще не связан)
```powershell
vercel link
```
Выберите:
- Существующий проект → выберите из списка
- Или создайте новый проект

### Шаг 4: Добавьте переменные окружения (если еще не добавлены)
```powershell
vercel env add NEXT_PUBLIC_SUPABASE_URL
vercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY
vercel env add SUPABASE_SERVICE_ROLE_KEY
```

Для каждой переменной:
- Введите значение
- Выберите окружения: Production, Preview, Development (или все)

### Шаг 5: Деплой!
```powershell
vercel --prod
```

Или используйте npm скрипт:
```powershell
npm run deploy
```

## Вариант 3: Автоматический скрипт

Запустите из корня проекта:

```powershell
.\setup-and-deploy.ps1
```

Скрипт автоматически:
- ✅ Проверит Vercel CLI
- ✅ Авторизует (если нужно)
- ✅ Свяжет проект (если нужно)
- ✅ Проверит переменные окружения
- ✅ Выполнит деплой

## ⚡ Самый быстрый способ (если все уже настроено)

Если проект уже связан с Vercel и переменные установлены:

```powershell
cd miniapp
vercel --prod --yes
```

## ❓ Проблемы?

### Ошибка: "Your codebase isn't linked"
```powershell
vercel link
```

### Ошибка: "Not authenticated"
```powershell
vercel login
```

### Ошибка: "Environment variable not found"
Добавьте переменные через Dashboard или CLI:
```powershell
vercel env add VARIABLE_NAME
```
